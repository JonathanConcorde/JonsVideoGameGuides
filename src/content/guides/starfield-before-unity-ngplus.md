## The key decision

Before entering Unity, decide whether the current universe is temporary or the one you want to develop long term.

If your next NG+ universe is intended to become the permanent outpost/manufacturing playthrough, do not over-invest in temporary infrastructure before Unity.

## What carries conceptually

Your most important preparation is not stockpiling physical resources. It is understanding the systems you want to rebuild quickly:

- Research priorities
- Skills
- Outpost layout
- Resource chain
- Manufacturing targets
- Preferred ship/loadout path
- Which quests unlock useful systems

## Powers

If you are optimizing for speed rather than completionism, weigh the time spent collecting additional powers against how much you value upgrading them before the next Unity.

Do not assume every optional power run must be finished before moving on.

## Research

Research that unlocks important outpost, crafting, weapon, suit, and manufacturing options can save significant time in the long-term universe.

Prioritize research that removes future bottlenecks.

## Skills

For an outpost/manufacturing-focused universe, useful skill investment generally falls into:

- Outpost construction
- Resource extraction
- Cargo/logistics
- Research
- Crafting
- Carry capacity/inventory management
- Commerce if selling manufactured output is part of the loop

## The first hours after Unity

Do not immediately recreate a giant industrial network.

Start by rebuilding the minimum systems needed to fund expansion:

1. Reliable weapons/gear
2. Credits
3. Construction resources
4. Basic outpost capability
5. Initial resource extraction
6. Central storage/manufacturing location

## Build the network in layers

### Layer 1 — Construction supply

Produce the materials needed to build more outposts.

### Layer 2 — Simple components

Automate useful common components.

### Layer 3 — Logistics

Add cargo links only where the resource flow is already stable.

### Layer 4 — Central manufacturing

Route outputs toward the main factory.

### Layer 5 — Advanced XP/credit production

Once the network is reliable, add more complex manufacturing.

## Why this order matters

A massive outpost chain built too early creates too many problems at once.

You want each stage to fund the next one.

That makes the system self-reinforcing instead of resource-hungry.

## Permanent-universe rule

Because this is the long-term universe, build deliberately.

It is worth spending extra time on:

- Better outpost locations
- Cleaner cargo routing
- Organized storage
- Expandable factory layout
- Comfortable central hub

Those improvements continue paying off for the rest of the playthrough.
